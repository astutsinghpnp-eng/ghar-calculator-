Assumptions & methodology used
  • All rates, wastage %, contingency (5%), transportation (3%), and labor (32%) are set on the backend — see api/estimate.js to change them.
  • Wall height fixed at 10 ft; soil type assumed medium; concrete mix M20; column count auto-estimated from built-up area — all backend defaults.
  • Windows assumed external, doors assumed internal (plus one main entrance door), consistent with the earlier version.
  • Washroom and bathroom sizes use standard defaults (5x4 ft and 6x5 ft) since only counts are collected on the frontend.
  • The total is shown as a range (±8%) rather than one exact figure, to reflect normal regional rate variance — treat the reference figure below it as a single-number approximation, not a quote.
  • This is a preliminary/detailed estimate, not a certified structural design — verify sizing with a licensed structural engineer before construction.
